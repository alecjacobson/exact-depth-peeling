# Complete-layer mesh measurements

The root README contains the figure, measured table, timing boundaries, and interpretation.
`config.json` identifies the executable, source files, machine quota, and numerical mode.
`summary.csv` contains three-repetition medians/ranges after one warm-up.
`status.jsonl` retains every attempted configuration, including timeouts and errors.
Per-configuration `metrics.json` files retain all repetitions and layer counters.
`audits.json` and `demo/metrics.json` record exact invariants and sampled independent ray ranks.
`demo/` contains the actual lifted layer meshes and the exploded Blender render.
